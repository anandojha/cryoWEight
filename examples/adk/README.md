# adenylate kinase example

A closed state prior steered onto open state cryo-EM images over 3 iterations of 2
weighted ensemble subiterations each. The seeding trajectory is generated by `run.sh`
with one nanosecond of explicit solvent MD, about three minutes on a GPU.

| | full system | example |
|---|---|---|
| WE subiterations | 25 | 2 |
| cryo-EM target `image.dcd` | 2,500 open frames | 250 open frames |
| seeding MD | 20 ns shipped | 1 ns generated |
| `n_pixel` | 200 | 64 |
| `N_draw` | 10,000 | 100 |
| segment length tau | 100 ps | 10 ps |

## Run

```bash
bash run.sh
```

The script assembles the run tree, generates the seeding trajectory if it is absent, and
runs the three iterations. Every setting is in `config.xml`. The explicit solvent system
holds 31,137 atoms, so run it on a GPU (`platform` is `CUDA` by default). The collective
variables are the NMP and LID opening angles.
