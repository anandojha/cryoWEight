# ntl9 example

An unfolded prior steered onto folded window cryo-EM images (RMSD 2.75 to 3.50 A) over
3 iterations of 2 weighted ensemble subiterations each. The seeding trajectory is
generated by `run.sh` with one nanosecond of implicit solvent MD, about one minute on a
GPU.

| | full system | example |
|---|---|---|
| WE subiterations | 40 | 2 |
| cryo-EM target `image.dcd` | 40,000 frames | 500 frames |
| seeding MD | 100 ns shipped | 1 ns generated |
| `n_pixel` | 128 | 64 |
| `N_draw` | 40,000 | 100 |
| segment length tau | 40 ps | 10 ps |

## Run

```bash
bash run.sh
```

The script assembles the run tree, generates the seeding trajectory if it is absent, and
runs the three iterations. Every setting is in `config.xml`. The protein holds 627 atoms
in OBC2 implicit solvent and runs on CPU or GPU.
